Private documents

No public
volume needed

The usual answer is “make the volume public”. That is the wrong answer.

  • The token carries the access rule, HMAC-signed
  • An unsigned request only reaches an already-published file
  • Set access: login and a guest gets the login screen
The usual answer
Publish the whole volume
Every file in it becomes public, because one brochure needed a viewer. The permission you wanted was per document; the one you had was per volume.
What Book does
A signed route, per document
expires.access.disposition.hmac — and the rule is read out of the token, never out of a query parameter. The volume stays private, the PDF still opens in the browser’s own viewer, and a CSV still renders as a table.

Twig

One call
takes anything

An asset, a URL, a handle, a document, or a field value.

  • The filter and the function are the same thing
  • Options at the call site beat the document’s own
  • A viewer’s knowledge sits under an author’s choice
